# 07 · Android 客户端

[返回总览](00-总览与索引.md)

本文件回答：手机 App 是什么、怎么连、能做什么、怎么验收。App 是 [06](06-图形界面.md) 同一份页面的安装壳：页面与能力只有一份，布局可以按端设计。

## 1. 定位

- App 是同一页面的安装壳：Kotlin 单 Activity 承载 WebView，加载内核托管的页面。
- 不内嵌前端构建产物：页面随内核升级，App 不随内核发版；只有壳改动才发版。
- 能力与电脑端相同：六页全部读写，见 [06](06-图形界面.md) §3 与 §7。
- 布局与桌面不同：手机单列、底部入口、全屏编辑页；桌面侧栏、双栏、弹层编辑。布局差异不影响能力。
- 瘦在壳，不瘦在能力：手机不排程、不判定、不存业务真相，但能发起全部写操作。
- 与手机浏览器的区别只有启动方式与图标：页面、认证、断线规则一致。形态选择见 [ADR 0011](adr/0011-手机端改为同一页面的安装壳.md)。

## 2. 技术栈

| 项 | 取值 | 说明 |
|---|---|---|
| 语言与界面 | Kotlin，单 Activity + WebView | 壳不写业务页面 |
| 最低版本 | minSdk 26（Android 8） | WebView 与明文 HTTP 可用 |
| 页面来源 | 内核托管，与 API 同源 | 页面、API、SSE 同源，不配跨域 |
| 明文 HTTP | 允许 cleartext；组网链路自带加密 | 局域网直连是 HTTP |
| 下载 | WebView 下载交给系统下载器 | 证据文件不落 App 私有目录 |
| 返回键 | 先退页面历史，根页再确认退出 | 与浏览器一致 |
| 构建与分发 | Gradle 签名 APK，GitHub Releases | 手动安装，覆盖安装保留 WebView 数据 |
| 时间显示 | 页面按手机本地时区显示，接口给 UTC | 换算在页面里 |

## 3. 启动与连接

- 首次启动：壳的引导页填地址（局域网 IP 或组网名称）；连接测试走 GET /api/v1/health。
- 地址存壳内；token 在页面「设置」里粘贴，存 WebView 本地存储。壳不读不写 token，不落日志。
- 换主机地址后要重新粘贴 token：页面存储按源隔离。
- 连接失败分三类提示：地址不可达、token 无效（401）、服务未启动；各自给下一步。
- 覆盖安装保留地址与已存 token；卸载后清空，重新导入。

## 4. 页面与能力

- 六页与电脑端相同：总览、作业、运行详情、环境、插件、设置（[06](06-图形界面.md) §3）。
- 手机布局：单列、底部入口、卡片替代表格；长表单分步或折叠；底部固定主操作。
- 字段与写操作不减少：同一字段、同一写操作都能到达并提交；不因窄屏删字段或改只读。
- 设置：与电脑端同一份设置；「关闭窗口」这类桌面项在 App 内不出现。
- 证据：缩略图与原图；原图交系统查看器，下载走系统下载器。

## 5. 断线与后台

- 前台连 SSE；断线按 1、2、4、8 秒退避重连，最长 30 秒，页面显示「重连中」。
- 重连带 Last-Event-ID；服务端补不齐时重取 /api/v1/status。
- 切到后台时 WebView 暂停，连接可能被系统断开；回到前台先拉快照再订阅。
- 离线只读，不排队写操作（P-707）。

## 6. 通知

- App 不做本地通知与前台服务：运行结束、停手、环境 failed 由服务端 Notifier 推外部通道（ntfy、Server酱）。
- 手机装对应通道的客户端接收；通知内容含结论、作业名、耗时、错误码、证据入口。
- 不做 FCM，不要求 Google 服务。

## 7. 边界

- 不做原生页面与原生表单：页面只有一份，布局按端设计。
- 不做离线缓存与后台常驻；不排队写操作。
- 不做语音、终端、文件编辑。
- 不做应用内自动下载与安装；新版 APK 从 Releases 手动覆盖安装。
- 不另存 token，不读页面存储。

## 8. 视觉

视觉与动效由页面统一实现，下限见 [06](06-图形界面.md) §10；App 不单独定义样式。WebView 版本随系统，老机型上模糊与动效降级。

## 9. 验收

| 编号 | 验收项 | 对应需求 |
|---|---|---|
| K-01 | 首次启动 1 分钟内完成地址导入与 token 粘贴，健康检查通过 | P-704、S-105 |
| K-02 | 冷启动到总览可交互 1 秒内（有快照），SSE 事件 1 秒内反映 | N-103、P-801 |
| K-03 | 六页全部可写：模板、计划表达式、插件配置、环境 prepare/reset、设置保存各走一遍 | P-705、AC-7、06 §11 |
| K-04 | 390 宽下字段与写操作清单与桌面逐项一致，无缺项、无只读降级 | P-705、06 §7 |
| K-05 | 断网 30 秒恢复后状态一致，事件不重复；离线写操作禁用并说明原因 | P-801、P-707 |
| K-06 | 叫停有二次确认；确认后最终状态为 cancelled，以 run.finished 为准 | P-304 |
| K-07 | 覆盖安装保留地址与 token；卸载后重新导入可用 | P-705 |
| K-08 | 证据原图由系统查看器打开；下载走系统下载器 | S-108 |
