# 07 · Android 客户端

[返回总览](00-总览与索引.md)

本文件回答：手机端 APK 是什么、三屏各做什么、怎么连、怎么验收。APK 是作品线客户端，不承载内核。

## 1. 定位

- APK 是平台的第二客户端，也是对外能拿出手的作品线交付物：把「随时看状态、随时叫停、随手改开关」带到手机上。
- 瘦客户端：业务真相在电脑侧内核，手机不排程、不判定、不存证据、不做重试。
- 三屏：总览、运行、设置。作业模板、计划表达式、插件配置的完整编辑在桌面窗口完成（[06](06-图形界面.md)）。
- 不耦合内核：只依赖 /api/v1 契约与 SSE；内核与插件升级不要求重新发版，契约不兼容时由服务端返回明确错误码。
- 技术选型理由见 [ADR 0002](adr/0002-手机端采用Android原生客户端.md)。
- 跨端一致：同一份状态快照与同一套事件语义，手机与桌面看到的结论一致。

## 2. 技术栈

| 项 | 取值 | 说明 |
|---|---|---|
| 语言与 UI | Kotlin + Jetpack Compose，单模块 | 三屏规模不值得拆模块 |
| 最低版本 | minSdk 26（Android 8） | 前台服务与通知渠道可用 |
| 网络 | OkHttp：HTTP/JSON 加 SSE | 命令走 POST，事件流走 GET |
| 状态 | ViewModel + Repository，单流向 | 不引入 MVI 框架 |
| 导航 | Navigation Compose | 三屏外加一个设置子页 |
| 令牌存储 | 应用私有存储（DataStore），不进日志与备份 | 硬件级密钥保护不属于一期必需 |
| 扫码 | CameraX + ML Kit bundled；无 Google 服务的设备用 ZXing | 只扫地址与 token 二维码 |
| 通知 | 本地通知加前台服务；外部通道用 ntfy | 不引入 FCM |
| 构建与分发 | Gradle 签名 APK，GitHub Releases | 手动安装，覆盖安装保留本地设置 |
| 时间显示 | 全部按手机本地时区，接口给 UTC | 只在显示层换算，不在本地存时间戳 |

## 3. 三屏

### 总览

目的：一屏看到「现在在做什么 / 今天成没成 / 能不能叫停」。

布局从上到下：

1. 顶栏：连接状态点（在线 / 重连中 / 离线）、最后更新时间、设置入口。
2. 当前运行卡：作业名、当前阶段、已用时间、attempt；没有运行时显示「待命」与下次触发时间。
3. 今日结论卡：completed / failed / unknown 计数；点数字进入运行列表。
4. 待处理卡：失败、unknown、环境 degraded、插件加载失败；点进对应运行或环境。
5. 底部固定操作：主按钮「叫停」，运行中可用；离线或重连中禁用并说明原因。

数据：

- 首屏取 GET /api/v1/status 全量快照，之后吃 SSE。
- 快捷动作：立即跑（选计划后 POST /api/v1/schedules/{id}/run，带 Idempotency-Key）、准备环境（POST /api/v1/environments/{id}/prepare）。

状态：

- 加载中：骨架卡，不整屏转圈。
- 空：未配置地址引导去设置；已连接无运行显示待命与下次触发。
- 错误：人话加错误码加重试。
- 离线：只读最近快照，写操作全部禁用。

### 运行

目的：看一次运行的阶段、attempt、结论与证据，并能叫停。

布局：

1. 顶栏：返回、运行 id、作业名、状态、已用时间。
2. 阶段时间线：prepare、execute、verify、cleanup 四段，各自状态（pending / running / ok / failed / skipped / timed_out）与耗时；失败段可展开错误码与原因。
3. attempt 列表：第几次、起止时间、结果；重试原因显示在对应 attempt 上。
4. 判定卡：verdict 三态、原因、证据缩略图；点图看原图。
5. 日志尾部：最近 50 行等宽字体；完整日志走证据下载，手机不拉全量。
6. 底部：叫停按钮；运行结束后变为「回总览」。

数据：

- GET /api/v1/runs/{id} 取运行、阶段、attempt、verdict。
- GET /api/v1/runs/{id}/events 是该运行的 SSE，事件 id 形如 `r:<run_id>:<seq>`，用 Last-Event-ID 续传（服务端保留最近 1000 条）；实时尾部同时按事件 id 合并去重。
- 证据：GET /api/v1/runs/{id}/evidence/{name}，缩略图先加载，原图按需。

状态：运行中、cleaning、succeeded、failed、unknown、cancelled；历史加载中、空、失败；翻页时保留阅读位置。

### 设置

目的：连接、通知、关于；只放手机端自己的设置。

- 连接：地址（局域网 IP 或 Tailscale 名称）、token 输入与粘贴、二维码扫描、连接测试（GET /api/v1/health）。
- 通知：运行结束、停手、环境 failed 三类开关；前台服务开关；ntfy 主题。
- 作业开关：计划启停（PUT /api/v1/schedules/{id}，带 If-Match，回写时保留其余字段），只切启用状态，不改表达式。
- 显示：深色模式跟随系统、字号档位。
- 关于：版本、构建号、当前主机 server_id、日志导出（不含 token）。

## 4. 叫停交互

叫停是危险动作，走底部确认层，不直接执行。

- 确认层内容：作业名、当前阶段、已用时间；影响说明（结束本次运行，环境按保温策略处置）。
- 主按钮「确认叫停」，次按钮「继续运行」；离线与重连中不可用。
- 提交 POST /api/v1/runs/{id}/stop，带 Idempotency-Key；服务端重复请求返回同一结果。
- 按钮进入「正在停止」，不乐观改成已停止；以 run.finished 或状态快照为准。
- 服务端拒绝（E_BUSY、E_NOT_FOUND）时保持原状并提示原因与错误码。

## 5. API 映射

| 界面动作 | 接口 | 说明 |
|---|---|---|
| 首屏快照 | GET /api/v1/status | 当前运行、今日结论、待处理、环境、下次触发 |
| 实时事件 | GET /api/v1/events | SSE；事件 id 为 `r:<run_id>:<seq>` 或 `g:<global_seq>`，断线重连带 Last-Event-ID |
| 运行列表 | GET /api/v1/runs?limit=20 | 按开始时间倒序 |
| 运行详情 | GET /api/v1/runs/{id} | 含阶段、attempt、verdict |
| 运行事件 | GET /api/v1/runs/{id}/events | 单运行的 SSE，用 Last-Event-ID 续传 |
| 证据 | GET /api/v1/runs/{id}/evidence/{name} | 缩略图与原图 |
| 叫停 | POST /api/v1/runs/{id}/stop | 带 Idempotency-Key |
| 立即跑 | POST /api/v1/schedules/{id}/run | 带 Idempotency-Key，重复提交返回同一运行 |
| 准备环境 | POST /api/v1/environments/{id}/prepare | 主按钮在总览快捷动作 |
| 计划启停 | PUT /api/v1/schedules/{id} | 带 If-Match，只改 enabled |
| 连接测试 | GET /api/v1/health | 返回 server_id 与版本 |
| 通知设置 | GET/PUT /api/v1/settings | 带 If-Match；不改与手机无关的键 |

所有请求带 Authorization: Bearer token；SSE 用请求头，不放 URL 查询参数。

## 6. 认证与网络

- token 写在平台配置里，桌面端设置页展示当前值；手机扫码或手输导入，之后只放在请求头（S-105）。
- 一期不做配对码、设备台账与多设备管理；撤销访问就是更换 token 并重启内核。
- 令牌存应用私有目录，不进日志、不进系统备份；卸载即失效。
- 地址两种：局域网 IP（在家）与 Tailscale 名称（在外）；界面不缓存「在不在家」，每次连接现测。
- 局域网内是 HTTP 加 token；Tailscale 链路自带加密，不另配证书。
- 连接失败分三类提示：地址不可达、token 无效（401）、服务未启动；各自给下一步。

## 7. 实时与断线

- 前台连 SSE；断线按 1、2、4、8 秒退避重连，最长 30 秒，页面显示「重连中」。
- 重连带 Last-Event-ID；服务端补不齐时要求重取快照，客户端重拉 /api/v1/status。
- 事件按 seq 去重合并；收到跳跃先补历史再渲染。
- 切到后台停止 SSE，前台服务按通知需要保留连接摘要。
- 离线时页面只读，不排队写操作（P-707）。

## 8. 通知

- 运行结束、停手、环境 failed 各发一条本地通知；内容含结论、作业名、耗时、错误码。
- App 在前台或前台服务持连时用 SSE 触发本地通知。
- App 被杀时外部通道兜底：ntfy 主题由服务端 Notifier 插件推送，手机订阅同一主题。
- 不引入 FCM，不要求 Google 服务。
- 通知点击直达运行详情；同一运行不重复通知。

## 9. 视觉与动效

| 项 | 取值 |
|---|---|
| 背景 | 深海 #06172B；网格白 4.3%、线宽 0.55dp、间距 42dp |
| 主色 | Ocean #2E6BE6；深色模式 #7EA8FF |
| 状态色 | 成功 #2EB85C；警告 #FFAD1F；失败 #FF3B30 |
| 玻璃 | 模糊 4–5dp；白面 0.5%–6%；白描边 0.8dp |
| 圆角 | 卡片 15–24dp；主按钮 18dp；输入 24dp；弹层 28dp |
| 字号 | 标题 22–32sp；卡片标题 18sp；正文 16sp；辅助 12–14sp |
| 触控 | 最小 48dp |

- 页面转场 260ms；卡片入场 220–280ms；弹层 160–220ms。
- 背景动画只在总览播放，30fps 上限；切页、滚动、手势期间冻结。
- 系统关闭动画（Animator duration scale = 0）时全部静止。
- 同屏玻璃卡不超过 3 个；低端机降级为半透明纯色加描边。

## 10. 状态覆盖

每屏覆盖：加载中、空、错误、离线、重连中。

- 离线与重连中：只读最近快照，叫停、立即跑、计划开关禁用并显示原因。
- 错误：人话加错误码与下一步；不显示堆栈与原始协议错误。
- 空：未连接引导设置；无运行显示待命；无历史显示说明。

## 11. 验收

| 编号 | 验收项 | 对应需求 |
|---|---|---|
| K-01 | 首次连接 1 分钟内完成：扫码或手输地址加 token，健康检查通过 | P-704、S-105 |
| K-02 | 总览首屏 1 秒内可交互（有快照），SSE 事件 1 秒内反映 | N-103、P-801 |
| K-03 | 断网 30 秒后恢复，状态与桌面端一致，事件不重复、不丢阶段 | P-801、P-707 |
| K-04 | 叫停有二次确认；确认后最终状态为 cancelled，界面以 run.finished 为准 | P-304、G-7 |
| K-05 | 运行详情能看到四阶段、attempt、verdict 与证据原图 | P-302、P-501、P-505 |
| K-06 | 通知可达：前台与后台各验证一次；点通知直达运行详情 | P-702、P-703 |
| K-07 | 出门用 Tailscale 名称可连，回家用局域网 IP 可连 | P-706 |
| K-08 | 三屏往返无崩溃；离线打开只显示缓存与「连不上电脑」 | P-707 |

## 12. 边界

- 不做作业模板、计划表达式、插件配置的完整编辑器；这些在桌面窗口完成，手机只切启用状态。
- 不做离线写操作与本地排队重放。
- 不做多主机切换界面；首期一台主机一条连接。
- 不做应用内自动下载与安装；新版 APK 从 Releases 手动覆盖安装。
- 不做证据编辑、删除与上传。
- 不做 FCM 推送、语音、终端、文件编辑。
- 不在手机上保存完整事件历史；只保留最近一次快照与当前运行。
