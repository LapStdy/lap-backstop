# 03 · 主界面判定与导航

[返回总览](../00-总览与索引.md) · [返回方舟日常](00-方舟日常.md)

本文件回答：平台怎样在任意主题、任意立绘与动态画面下判定「已在主界面」；以及平台自己的方舟导航如何用同一个判定。判定器的模块、帧来源、冻结样本与测试口径见 [04-主界面探针实现](04-主界面探针实现.md)。

## 两个用途

| 用途 | 要求 | 判定参数 | 判不出时 |
|---|---|---|---|
| 交接给 MAA | 宽容：认不出可以让 MAA 自己导航过去 | 总分 ≥ 8，外观命中 ≥ 2，连续 2 帧 | 交棒并写 `run.signal`（`maa.gate.unknown`） |
| 自身导航 | 严格：提前认成主界面会在错误页面上执行后续动作 | 总分 ≥ 10，外观命中 ≥ 4，连续 3 帧 | 有界返回重试，超预算停手 |

误判方向也不对称：交接用途里把非主界面认成主界面，代价是 MAA 多走一遍启动流程；导航用途里同样的误判会让平台在错误页面上点下去。所以两个用途的门槛不同，判定器是同一个。

## 页面状态

| 状态 | 含义 | 交接用途 | 导航用途 |
|---|---|---|---|
| `HOME` | 主界面 | 交棒 | 到达目标 |
| `OVERLAY` | 已知覆盖层：维护、更新、掉线、退出确认、公告、签到 | 停手并通知 | 停手并通知 |
| `OTHER` | 其它页面，或无法归类 | 交棒并记事件 | 按返回，有界重试；判定达导航档分数但连续帧未满时仍记 `OTHER`，不按返回、继续采样确认 |

## 判定依据：主题无关锚点

主界面顶部与左侧有一排由基础界面层绘制的固定件。主题改变配色、字体、背景美术、干员立绘、活动横幅与动态效果，不改变这些固定件的位置与形状，因此判定只使用它们，不读任何文字。

| 锚点 | 位置框（1280×720） | 参与通道 | 状态变体 |
|---|---|---|---|
| 设置齿轮 | `(27,19,41,41)` | 外观 + 位置 | 1 |
| 公告三角 | `(97,19,44,39)` | 外观 + 位置 | 1 |
| 日历 | `(247,21,53,36)` | 外观 + 位置 | 2：带未读角标、不带角标 |
| 寻访凭证 | `(1053,27,41,49)` | 外观 | 1 |
| 主界面 ⟳ 圆按钮 | `(290,391,29,24)` | 外观 | 1 |

模板规则：

- 只截字形主体，不含角标、数字与状态带；带角标的状态单独存一个变体。
- 每锚点允许 1–2 个状态变体，命中任一变体即算该锚点命中。
- 匹配前把高饱和像素（`S > 110` 且 `V > 130`）置为灰度 128，消除橙黄角标与徽标的影响。

## 两路打分

| 通道 | 算法 | 单锚点分值 |
|---|---|---|
| 外观 | `cv2.matchTemplate` + `TM_CCOEFF_NORMED`，得分 ≥ 0.85 且位置偏移 ≤ 16 像素 | 2 |
| 位置（同位素） | 位置框内与局部中位数相差超过 45 的像素占比超过阈值；只看「这个位置有没有图标结构」，不看颜色与极性 | 1 |

位置通道只用于左上三个图标，阈值：齿轮 0.26、公告 0.33、日历 0.31。阈值在按主题划分的拟合集上确定，验证集只用于验收，不参与调参。单锚点两通道合计上限 3 分，五个锚点满分 15。

位置通道的价值在于图标外观被主题重绘时仍能得分；它单独不足以判定，负样本在它上面能拿到 2 分。

## 实测基线

冻结样本 42 帧：主界面 22 帧（默认主题 12、节日 3、水墨 1、暗紫 3、红龙 3）；非主界面 20 帧（公告面板、仓库、活动页各 1 帧，签到面板 3 帧含两个滚动位置，基建 3 帧含总览 1 帧，登录与载入 11 帧）。

| 指标 | 结果 |
|---|---|
| 主界面判定 | 21/21 为 `HOME`，总分最低 11 |
| 非主界面误判 | 0/17，总分最高 0 |
| 单帧耗时 | 3.4–4.1 毫秒 |
| 锚点位置跨主题偏移 | 0 像素 |

验收判据：新增主题或游戏改版后，主界面样本全部达到交接门槛，非主界面样本全部总分 ≤ 2；任一条不满足即不放行，回到覆盖层判定与导航重试。

## 不采用的证据源

| 证据源 | 不采用的原因 |
|---|---|
| 游戏内部状态（`shared_prefs`） | 76 个键中没有主题键，主界面状态不落盘 |
| 无障碍树 | 游戏为 Unity 自绘，`uiautomator dump` 只返回 Android 容器节点 |
| 游戏日志事件 | logcat 中 Unity 输出只在启动瞬间出现，没有持续的界面状态事件；无 `Player.log` |
| 小范围文字 OCR | 正判已满、误判为零，OCR 只会增加误放行风险；装饰字体下字迹最不可靠 |
| 逐主题模板集 | 主题数量增长使每个入口都要维护一套模板；只作备用链末段 |

## 导航

所有页面切换以主界面为中转（星型拓扑）：进入页面、做完、退回主界面，再进入下一个页面。这样只需可靠识别主界面一个页面，其它页面只需判「不是主界面」。

导航控制器在 `plugins/maa/vision/navigation.py`，入口 `ensure_home`，四个端口经 `NavigationPorts` 注入：帧来源（`FrameSource`）、判定器（`ScreenJudge`，判读为 `home` / `overlay` / `other` 三态，附总分与外观命中数）、返回键（`BackSender.send_back`）、战斗门（`BattleGate.in_battle`，默认实现恒答不在战斗）。

```text
ensure_home(预算 limit = 3):
    循环：采样 → 判定
    ├─ HOME（导航档连续第 3 帧达标）→ 成功
    ├─ OVERLAY  → 停手（原因码 overlay）
    ├─ 达导航档但连续帧未满 → 不按返回，回到采样继续确认
    ├─ 战斗中   → 停手（原因码 in_battle），不发送返回键
    ├─ 截帧失败 → 停手（原因码 no_frame）
    └─ OTHER    → 预算未尽：按返回 → 即时再判定 → 仍非 HOME 才等待 0.4–0.8 秒 → 回到采样
                预算用尽：停手（原因码 budget_exhausted），不再按键
    按后即时判定：HOME → 成功；OVERLAY → 停手（原因码 overlay）；其余 → 等待后重新采样
```

- 预算 `limit` 默认 3；等待区间 0.4–0.8 秒随机，经注入的等待函数生效，测试注入零等待。
- 每次按返回前后各判定一次（按前判定、按后即时判定），不连续盲按；按后判定仍非主界面才等待并重新采样。
- 达导航档分数但连续帧未满的帧不按返回：主界面上按返回会弹出退出确认框，所以达标帧只继续采样，累计连续 3 帧才判到家；期间任一帧未达导航档把连续计数清零，回到按返回流程（仍受预算约束）。
- 逐步证据随返回值给出，不写文件、不发事件：每条含采样序号、当次判读（结论、总分、外观命中数）、是否按了返回、原因码；条数等于判定次数，截帧失败的那次采样没有判定，不产生条目。
- 主界面判定器到 `ScreenJudge` 端口的适配（`HomeJudgeAdapter`：导航档连续 3 帧达标判 `home`，未满连续帧与只达交接档的帧判 `other`，覆盖层先经登录判读）与 prepare 接线随 `navigation` 开关生效，开关默认关；覆盖层处置（关闭、通知）与退出确认框取消属后续卡。
- 战斗中不发送返回键；`ensure_home` 的前置条件是当前不在战斗。
- 主界面上多按一次返回可能弹出「退出游戏」确认框；该确认框按 `OVERLAY` 处理，取消动作在点击白名单内。返回预算不含确认框的额外消耗。

## 证据

每次判定写入：通道、ROI、锚点名、得分、位置偏移、命中票数、总分、判定结果、截图哈希与时间戳。交接用途额外写一条 `run.signal`（`maa.gate.unknown`）；导航用途的逐步证据由导航控制器随返回值给出（采样序号、判定结论、总分、外观命中数、是否按了返回、原因码），不直接写证据文件与事件。

## 性能

| 动作 | 耗时 |
|---|---|
| 5 个锚点外观匹配 | 3.4–4.1 毫秒 |
| 3 个位置通道 | 计入上面的 3.4–4.1 毫秒 |
| adb 截图 | 约 600 毫秒 |
| MuMu 原生截图 | 10–150 毫秒 |

导航循环的瓶颈在截图通道：判定本身 3.4–4.1 毫秒可忽略；每次按返回后控制器至少再截两帧（按后即时判定与等待后的复核采样），adb 通道每帧约 600 毫秒，原生通道每帧 10–150 毫秒。

## 失败处置

| 情形 | 处置 |
|---|---|
| 主界面样本总分低于交接门槛 | 重新采集稳定帧复测一次；仍不达标记 `unknown` |
| 未知主题 | 交接交棒并记事件；导航有界返回后停手 |
| 命中覆盖层 | 按覆盖层策略关闭或停手，不交棒 |
| 分辨率不是 1280×720 | 返回 `E_ENV_RESOLUTION`，不缩放后继续识别 |
| 判定与预期矛盾 | 记证据，交 Advisor 分诊 |
