# 00 · 总览与索引

[返回 README](../README.md)

## 一句话

把一台 Windows 电脑上的外部自动化脚本托管起来：在正确的时间、正确的环境状态下执行，监督过程，验证结果，失败按策略恢复，任何地方可看可停。

## 系统边界

~~~text
客户端：电脑端 WebView2 + 托盘 / 手机浏览器 / 手机 App（同一页面的三种装法）
                    │ HTTP / SSE
核心 supervisor：调度、作业、环境、资源、插件、恢复、事件、API、存储
                    │ worker 进程
插件：MAA、MAAEnd、fake、通知、AI Advisor
                    │
外部：MuMu、方舟、终末地、MAA、MAAEnd
~~~

平台内核不认识「明日方舟」，也不认识「MAA」；它只认识环境、作业、资源、插件与事件。游戏与脚本的差异在插件里。

## 对象模型

~~~text
Schedule ──> JobRun ──> Phase(prepare → execute → verify → cleanup) ──> Event / Evidence
                │
                ├─ ResourceLease ──> Environment
                ├─ JobTemplate ──> Plugin（环境 + 脚本 + 验证 + 恢复）
                └─ Verdict / Notification
~~~

| 对象 | 含义 |
|---|---|
| 插件 | 扩展包；声明能力与配置 schema。 |
| 环境 | 外部运行环境；有独立状态机。 |
| 脚本 | 被托管的外部程序。 |
| 作业模板 | 环境 + 脚本 + 验证策略 + 恢复策略。 |
| 调度 | 何时触发；补跑、合并、优先级、预热、保温。 |
| 运行 | 一次执行；包含四个阶段与若干 attempt。 |
| 资源 | 环境、账号、GPU 等互斥资源。 |
| 租约 | 资源使用凭证；带 TTL 与续租。 |
| 事件 | 运行中追加写入的事实。 |
| 证据 | 可复核的截图、日志、探针结果、退出状态。 |
| 结论 | completed / failed / unknown。 |
| 建议 | AI 旁路输出，只出主意。 |

## 术语

| 词 | 含义 |
|---|---|
| Plugin | 扩展包；manifest + 能力实现 + 配置 schema。 |
| Capability | 插件能力：environment、script、verifier、config_projection、notifier、advisor。 |
| Environment | 外部环境，例如 MuMu + 方舟、终末地客户端。 |
| JobTemplate | 作业模板；组合环境、脚本、验证与恢复策略。 |
| Schedule | 调度；cron / at / interval。 |
| JobRun | 运行；状态机与 attempt。 |
| Phase | prepare / execute / verify / cleanup。 |
| ResourceLease | 资源租约；TTL、续租、释放。 |
| Verdict | 结论；completed / failed / unknown。 |
| VerificationPolicy | 验证策略；由作业模板保存完整结构，验证器解释 `params`。 |
| Evidence | 证据；截图、日志、探针结果、退出状态。 |
| Preheat | 预热；在计划时间之前启动环境。 |
| KeepWarm | 保温；运行结束后保持环境就绪。 |
| Advisor | AI 建议能力；旁路，不进主路径。 |

## 一期范围

一期只做一件事：**MAA 插件完成「预热 → 就绪 → 执行 → 验证 → 通知」闭环，在慢机器上连续 7 天无人值守**。平台内核、fake 插件、MAA 插件是必做；MAAEnd 插件随后接入，用来验证「通用」不是空话；界面按「手机能做完电脑端的事」实现：六个页面一份代码，先按手机宽度验收，桌面宽屏随后；手机 App 安装壳在页面稳定后接入。

## 四条不可妥协

1. **内核不依赖具体脚本与游戏**：插件换掉，内核行为不变。
2. **配置是数据，执行是插件代码**：用户可编辑内容由插件 schema 定义；执行逻辑不进通用 DSL。
3. **平台数据库是唯一真源**：外部系统通过插件 config projection 同步；差异由插件声明策略。
4. **结论有证据，动作有事件**：每条结论可复核，每个动作可追溯。
