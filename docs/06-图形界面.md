# 06 · 图形界面

[返回总览](00-总览与索引.md)

本文件回答：桌面窗口、手机浏览器与手机 App 怎样看到并操作平台。界面不含业务真相，全部经 /api/v1 读取与修改。

## 1. 原则

- 内核无界面；界面是客户端，退出界面不影响运行。
- 一份页面，三种装法：桌面 WebView2 窗口加托盘常驻、手机浏览器、手机 App 安装壳（见 [07](07-Android客户端.md)）。
- 手机与桌面是同一份页面：宽度只改布局密度（单列、底部入口、卡片折叠），不隐藏字段、不禁用写操作。
- 界面不把本地缓存当真相：SSE 断线按 Last-Event-ID 只补缺失段，服务端补不齐时重拉 `/api/v1/status` 快照。
- 写操作幂等或带版本校验，重试不产生重复副作用。

## 2. 桌面端形态

| 项 | 取值 |
|---|---|
| 技术 | pywebview（WebView2）渲染页面，pystray 提供托盘 |
| 启动 | 随用户登录启动；内核未运行时先拉起内核，再开窗口 |
| 窗口 | 最小 1024×640，默认 1280×820；单实例，重复启动只激活已有窗口 |
| 关闭窗口 | 设置项「收进托盘」或「退出界面」；两者都不停内核 |
| 托盘菜单 | 打开窗口、当前状态、立即跑一次、停止当前运行、退出界面 |
| 托盘气泡 | 运行结论、停手、环境 failed 各弹一次，同一运行只弹一次 |
| 单实例 | 命名互斥量；第二个实例把参数转交第一个实例后退出 |

- 内核默认监听 127.0.0.1:8787，端口可配；改端口要同步客户端设置。
- 窗口只在登录会话内工作：内核需要交互式桌面（MuMu 是桌面 GUI 程序），服务化不在界面范围。

## 3. 页面

| 页面 | 回答的问题 | 主要区块 |
|---|---|---|
| 总览 | 现在什么状态、今天成没成、有没有要人处理的 | 当前运行卡、今日结论、待处理、环境状态条、租约、快捷动作 |
| 作业 | 有哪些作业模板与计划 | 模板列表与参数表单、计划列表（类型、表达式、下次触发、启用）、立即跑 |
| 运行详情 | 这次运行怎么走的、为什么是这个结论 | 阶段时间线、attempt、事件流、verdict 与证据、日志尾部、停止按钮 |
| 环境 | 环境能不能用、被谁占着 | 状态与最近迁移、probe 结果、prepare 与 reset、保温剩余、租约与 TTL |
| 插件 | 装了哪些插件、能做什么、配置是什么 | manifest 只读信息、capabilities、schema 表单、配置 revision、契约测试结果、加载错误 |
| 设置 | 认证、通知、保留、备份、宿主 | 当前 token、通知通道、保留期、备份导出、计划任务注册、关闭行为、关于与版本 |

总览的判读顺序：

1. 当前运行：显示作业名、阶段、已用时间与停止按钮；无运行时显示下次触发与保温剩余。
2. 今日结论：completed / failed / unknown 计数，点数字进运行列表。
3. 待处理：失败、unknown、环境 degraded、插件加载失败，按发生时间倒序。
4. 环境与租约：每个环境一行，显示状态与占用者，可一键 prepare 或 reset。

作业页的模板表单由插件 schema 生成；计划的类型、表达式、补跑策略、优先级、截止时间、预热与保温都在同一表单里编辑。

## 4. schema 驱动表单

插件配置全部由 manifest 的 config_schema（JSON Schema）生成，界面不为单个插件写表单。

| schema | 控件 | 校验 |
|---|---|---|
| string | 单行输入 | minLength / maxLength / pattern |
| string + enum | 下拉 | 值必须在 enum 内 |
| string + format=path | 路径选择器 | 必须落在声明根目录内（S-107） |
| integer / number | 数字输入加步进 | minimum / maximum / multipleOf |
| boolean | 开关 | 无 |
| array（标量） | 标签输入，可增删 | item schema 逐项校验 |
| object | 分组卡片，可折叠 | properties 递归生成 |
| 只读字段 | 文本展示 | 由后端返回，表单不提交 |

- 表单校验只做即时提示；落库前由内核按 schema 再校验，失败返回 400 与字段路径。
- 未知字段原样保留并回写，避免内核不认识的新字段被界面丢弃。
- 保存带 revision 与 If-Match；版本不符返回 409，界面展示字段级差异后让用户重载。
- 配置以插件 payload 不透明存储，界面只展示 schema 声明过的字段。

## 5. 证据

| 项 | 行为 |
|---|---|
| 列表 | 缩略图 160 像素宽，懒加载；按类型给图标（截图、日志片段、退出码） |
| 原图 | 点击打开查看器，原图按证据 id 取回，支持适应窗口与 1:1；不自动下载全部原图 |
| 关联 | 每条证据挂在运行与事件上，从 verdict 或事件流都能点开 |
| 过期 | 超过保留期的证据标「已过保留期」，不给下载入口，verdict 仍可查 |
| 只读 | 界面没有编辑或删除证据的入口；清理只由保留策略执行 |

## 6. 实时与 SSE

- 订阅 GET /api/v1/events；事件 id 在运行内为 `r:<run_id>:<seq>`、全局事件为 `g:<global_seq>`，断线重连带 Last-Event-ID，服务端保留最近 1000 条事件。
- 事件类型：run.created、run.queued、run.state.changed、run.phase.started、run.phase.finished、run.signal、run.verdict、run.finished、run.interrupted、env.state.changed、resource.leased、resource.renewed、resource.released、recovery.started、recovery.finished、evidence、notify.sent、notify.failed、plugin.loaded、plugin.rejected、config.applied、config.rolled_back、deprecation.used、advisor.requested、advisor.responded、advisor.rejected、advisor.degraded、advisor.budget_exhausted、advisor.disabled、host.state、host.event、core.event、heartbeat。
- 合并去重：按事件 id 单调合并；补不齐时重取 /api/v1/status 全量快照。
- 背压：慢客户端被内核断开并提示重新同步，不阻塞写入（P-805）。
- 心跳事件缺失连续三个周期视为离线。
- 页面不可见时暂停动画与背景刷新，恢复时先补快照再订阅。

## 7. 响应式与手机宽度

| 断点 | 布局 |
|---|---|
| ≥ 1200 像素 | 左侧导航加内容双栏；运行详情左右分栏（时间线 / 证据） |
| 768–1199 像素 | 顶部导航加单栏；表格允许横向滚动 |
| < 768 像素 | 单列；底部入口（总览、作业、运行、更多），环境、插件、设置在「更多」；表格改卡片或横向滚动 |

- 布局按端设计：手机是单列、底部入口、全屏编辑页；桌面是侧栏、双栏、弹层编辑。两套布局各自独立，不互相迁就。
- 能力不按端分叉：同一字段、同一写操作在两种布局里都可达；放不下用分步、折叠、子页，不删字段、不禁用操作。
- 触摸目标最小 44 像素，表单控件不小于 40 像素高。
- 长列表不做无限滚动：超过 50 条给分页。
- 截图与证据按需加载，弱网先出文字后出图。
- 深色模式跟随系统；字号可调，正文 16 像素起。

## 8. 远程访问

- 内核默认只监听 127.0.0.1；开启远程后监听 Tailscale 接口地址，不监听公网网卡，不做端口映射。
- 认证：Authorization: Bearer token；token 写在平台配置里，桌面端设置页展示当前值供导入。
- 首次连接：桌面端显示地址与 token；手机 App 填地址后在页面设置里粘贴 token，手机浏览器打开地址后同理。
- 不建配对码与设备台账；撤销访问就是更换 token 并重启内核（S-105、P-704）。
- 出门一律走 Tailscale，局域网内可直连。

## 9. 通知

- 桌面托盘气泡与界面内告警是补充通道，不替代外部通知（P-701、P-702）。
- 运行结束、停手、环境 failed 各弹一次；同一运行不重复弹。
- 通知内容：结论、作业名、耗时、错误码、证据入口。
- 外部通道（Server酱、钉钉、ntfy）由内核通知服务发送，界面可开关；测试连通性调用 POST /api/v1/notifications/test，把结果（成功与否、渠道、耗时、失败原因）直接展示，不做本地假发送。
- 界面不设静音时段；需要安静时关托盘气泡，外部通道照常发送。
- 设置页通知区列出投递历史：数据来自 GET /api/v1/notifications（默认最近 100 条），每条含渠道、状态（pending/sent/failed）、尝试次数、发送时间与失败原因；测试投递不进这份历史。

## 10. 状态与可访问性

每个页面覆盖四种状态：加载中、空、错误、离线。

- 加载中：骨架屏，不整屏转圈；超过 3 秒显示「仍在加载」与取消。
- 空：说明为什么空（未装插件、未建计划、今天还没跑），给下一步入口。
- 错误：人话加错误码加重试；不显示堆栈。
- 离线：顶栏标离线，只读最近快照，写操作禁用并说明原因。

- 键盘可达：Tab 顺序与视觉顺序一致，Esc 关闭弹层。
- 颜色对比度正文不低于 4.5:1；状态不只靠颜色区分，配文字标签。
- 动效 160–240 毫秒；系统要求减少动画时关闭。

## 11. 验收

| 编号 | 验收项 | 对应需求 |
|---|---|---|
| G-1 | 关闭窗口后内核与当前运行继续；托盘可重新打开并看到同一状态 | P-705 |
| G-2 | 六个页面在 1024 宽与手机 App 390 宽下均可用且可写，无横向错位 | P-705、第 7 节 |
| G-3 | 插件表单由 schema 生成，非法值被 400 拒绝并定位字段；并发保存返回 409 | P-404、P-708 |
| G-4 | 断网 30 秒后恢复，界面状态与内核一致，事件不重复不丢 | P-801、P-805 |
| G-5 | 运行详情能看到四个阶段、attempt、verdict 与证据原图 | P-302、P-501、P-505 |
| G-6 | 无 token 或错 token 的请求拿不到任何业务数据 | P-704、S-108 |
| G-7 | 手机与桌面都能完成同一套操作：叫停、准备环境、启停计划、改模板、改插件配置 | P-705、AC-7 |
| G-8 | 390 宽与 1280 宽下可用操作集合一致：字段与操作清单逐项比对无缺项 | P-705、第 7 节 |
