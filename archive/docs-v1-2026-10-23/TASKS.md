# 任务清单

只记「还没做的事」。做完的进提交说明或交接账本。

## 一期：技术验证

先花几天把四个不确定点点掉，再写正式代码。

- [ ] 掉线与恢复：游戏断线（MAA 日志「游戏掉线，停止任务」）的检测、重连与停手口径。
- [ ] 后置动作核对：结束状态（主界面、错误框、掉线、维护、更新、未知）模板与误判率；MAA 完成后动作接管后的收尾顺序。
- [ ] MuMu 原生通道：`external_renderer_ipc.dll` 的调用签名与稳定性，作为快速截图备选。
- [ ] 原生通道对比：同场景下 MuMu 原生截图与 adb 截图的耗时、成功率与失效条件。

## 一期：实现顺序

- [ ] M0 骨架：环境与依赖、门禁、FastAPI、SQLite、配置加载、doctor 自检。
- [ ] M1 ADB 控制：连接管理、截图、点击、滑动、返回、截图存证。
- [ ] M2 识别：模板采集工具、模板验收、ROI 匹配、帧差、干跑模式。
- [ ] M3 前置操作：音量、防睡眠、模拟器复用、拉起游戏、等登录、点登录、等主界面。
- [ ] M4 MAA 交接：写入任务配置、启动 MAA、日志观察、抽帧、结束检测。
- [ ] M5 判定与证据：三态结论、判定等级（脚本 / 画面 / 双证据）、后置动作（结束画面核对）、证据归档、事件流、回放。
- [ ] M6 兜底：卡住、崩溃、错误框、重试预算、停手通知。
- [ ] M7 调度与停止：计划任务、开机自启、待命、停止运行、托盘小窗。
- [ ] M8 通知：钉钉与 Server酱³，通道可配。
- [ ] M9 只读看板：电脑端窗口与 Android 安装包，状态、历史、截图。
- [ ] M10 连续 7 天无人值守验证。
