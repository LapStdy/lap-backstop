# 07 · Android 客户端

[返回总览](00-总览与索引.md)

## 定位

手机端是 Android 安装包，电脑端是 WebView2 窗口。两端共用同一套 HTTP API 与 SSE 事件；手机端是瘦客户端，业务判断与数据都在电脑侧。

M0 只做三屏：**总览、运行详情、配对与设置**。目标是验证观感、配对、SSE 断线恢复与叫停，不做完整编辑器。本轮只落设计与交互，不建 Android 工程、不写代码、不跑模拟器。

## 技术栈

已定：

- Kotlin + Jetpack Compose，单模块起步。
- HTTP + SSE；命令走 HTTP POST。
- Android Keystore 存长期令牌；服务端只存 SHA-256 摘要。
- 签名 APK + GitHub Releases。
- 出门优先 Tailscale；不默认公网 Tunnel。

可后定，先给默认：

| 项 | 默认 | 说明 |
|---|---|---|
| minSdk | 26（Android 8） | 覆盖 Keystore、前台服务；低版本可按目标机调整 |
| 玻璃库 | `io.github.kyant0:backdrop` 1.0.6 | 与 dsh-mobile 同源；跨端再换 Haze 2.x |
| 背景 | API 33+ AGSL，低版本径向渐变 | 30fps 节流，手势期间冻结 |
| 扫码 | CameraX + ML Kit bundled | 无 Google Play services 时改用 ZXing |
| 通知 | 本地通知 + ntfy | FCM 只在需要商店分发时再评估 |
| 导航 | Navigation Compose | 三屏足够，不引入复杂路由库 |
| 状态 | ViewModel + Repository | 不引入 MVI/Redux 式强类型信封 |

## M0 三屏

### 1. 总览

目的：一屏看到「现在在做什么 / 今天成没成 / 一键叫停」。

布局从上到下：

1. 顶栏：连接状态点（在线 / 重连中 / 离线）、最后更新时间、设置入口。
2. 当前运行卡：编排名、当前步骤、已用时间、进度；没有运行时显示「待命」与下次触发时间。
3. 今日结论卡：完成 / 未完成 / 判不出；附判定等级、最近一次运行时间与证据入口。
4. 待处理卡：冲突、失败、判不出；点进对应详情。
5. 底部固定操作：主按钮「叫停」；运行中才可用，离线/重连中禁用并说明原因。

数据：

- 首屏取 `GET /api/status` 全量快照。
- 之后吃 `GET /api/events` 的 SSE：`run.started`、`step.started`、`step.finished`、`judgement`、`run.finished`、`conflict.detected`、`heartbeat`。
- 断线重连带 `Last-Event-ID` 或 `since_seq`；补不齐时重取快照。

状态：

- 加载中：骨架卡，不转圈盖全屏。
- 空：未配对 → 引导去第三屏；已配对无运行 → 显示待命与下次触发。
- 错误：人话 + 重试；不显示堆栈。
- 离线：只读最近快照，写操作全部禁用。

动效：

- 连接状态点 7–8dp，在线时 5dp 光晕、28% 透明；重连中琥珀，失败红。
- 卡片入场 220ms 淡入 + 轻微上移；不做逐条列表动画。
- 首页背景只在总览播放；切到详情暂停，省电。

### 2. 运行详情

目的：看一次运行的步骤、判定与证据，并能叫停。

布局：

1. 顶栏：返回、运行 id / 编排名、状态、已用时间。
2. 步骤时间线：每步显示名称、状态（pending/running/ok/failed/skipped/blocked）、耗时、重试次数；失败步骤标红并可展开原因。
3. 判定卡：结论三态、判定等级、核对项、原因、证据缩略图；点图看大图。
4. 日志摘要：最近 N 行，等宽字体；完整日志走证据下载，不在手机端拉全量。
5. 底部：叫停按钮；只读完成后变为「回总览」。

数据：

- `GET /api/runs/{id}` 取详情与步骤。
- `GET /api/runs/{id}/events` 取历史事件，`before_seq` 分页；实时尾部走全局 SSE，按 `seq` 合并去重。
- 证据：`GET /api/runs/{id}/evidence/{name}`，按需加载缩略图/原图。

状态：

- 运行中、已完成、失败、判不出、已中断。
- 历史加载中、空、加载失败；滚动到顶部加载更早事件，保留当前阅读位置。

动效：

- 步骤状态变化用 220ms 颜色/透明度过渡；时间线节点不跳动。
- 判定卡入场 280ms 淡入 + 0.96→1 缩放；失败时边框变红，不做闪烁。
- 页面转场 260ms 左滑/右滑。

### 3. 配对与设置

目的：首次连接、设备管理、通知与连接配置。

首次配对：

1. 电脑端显示二维码；手机点「扫码配对」。
2. 相机扫到 Base64URL 载荷，解析 `version/baseUrl/pairingCode/expiresAt/serverId/endpoints`。
3. 先探测 `GET /api/health`：成功 / 失败 / 超时三态；失败可改地址，不写半条记录。
4. 显示设备名（可改），提交 `POST /api/pair`；成功后令牌进 Keystore，设备出现在电脑端列表。
5. 配对码一次性、默认 5 分钟；过期或重复使用显示明确错误并回到扫码。

设置项：

- 连接：局域网地址 / Tailscale 地址切换；当前网络状态每次现算，不缓存「在不在家」。
- 设备：设备名、最后在线、撤销本机；撤销后清令牌并回配对页。
- 判定：默认等级只读展示。
- 通知：完成 / 需要人工 / 失败三类开关；前台服务监控开关；ntfy 主题。
- 更新：当前版本、检查更新、下载并校验 SHA-256。
- 关于：许可、版本、日志导出。

数据：

- `POST /api/pair`、`GET /api/devices`、`DELETE /api/devices/{id}`、`GET /api/health`。
- 扫码失败、地址不可达、配对码过期、设备已撤销分别给不同提示。

动效：

- 扫码页进入 220ms 淡入；取景框四角用 160ms 呼吸，不遮挡相机。
- 配对成功用一次 300ms 绿色对勾 + 轻触感，不弹全屏庆祝。

## 叫停交互

叫停是危险动作，单独做底部确认层，不直接执行。

确认层内容：

- 当前运行：编排名、当前步骤、已用时间。
- 影响：结束本次运行，关闭 MAA、游戏与模拟器；程序退出后由计划任务拉起。
- 主按钮「确认叫停」；次按钮「继续运行」。
- 离线/重连中不可用，显示「连接恢复后可操作」。

提交：

- `POST /api/runs/{id}/stop`，带 `requestId` 防重复；服务端 2 分钟内幂等。
- 按钮进入「正在停止」，不乐观改成已停止；以 `run.finished` 或状态快照为准。
- 服务端拒绝（`E_BUSY`、运行已结束）时保持原状并提示。

按住确认可以作为二期加强：长按 600–800ms 才提交，断线/超时视为未确认。M0 先用二次确认层。

## 视觉与动效

设计 token 来自 [research/02](research/02-手机端界面与动效.md)：

| 项 | 值 |
|---|---|
| 背景 | 深海 `#06172B`；网格白 4.3%、线宽 0.55dp、间距 42dp |
| 主色 | Ocean `#2E6BE6`；深色模式 `#7EA8FF` |
| 成功/在线 | `#2EB85C` |
| 警告/连接中 | `#FFAD1F` |
| 失败 | `#FF3B30` |
| 玻璃 | 模糊 4–5dp；白面 0.5%–6%；白描边 0.8dp；外阴影黑 9% |
| 圆角 | 卡片 15–24dp；主按钮 18dp；输入 24dp；弹层 28dp |
| 字号 | 标题 22–32sp；卡片标题 18sp；正文 16sp；辅助 12–14sp |
| 触控 | 最小 48dp |

动效：

- 页面转场 260ms；卡片入场 220–280ms；弹层 160–220ms。
- 抽屉/底部层用 spring(450, 无回弹)；不做逐条列表进场。
- 背景 30fps 上限；切页、滚动、手势期间冻结；系统「移除动画」时静止。
- 尊重 `prefers-reduced-motion` 的 Android 等价设置（Animator duration scale = 0）。

性能：

- 背景只在总览；详情页用静态渐变。
- 玻璃卡同屏不超过 3 个；低端机降级为半透明纯色 + 描边。
- 证据图用缩略图，原图按需；列表不预加载全量。

## 数据与接口映射

| 界面 | 接口 / 事件 |
|---|---|
| 总览 | `GET /api/status`；SSE `run.started`、`step.started`、`step.finished`、`judgement`、`run.finished`、`conflict.detected`、`heartbeat` |
| 运行详情 | `GET /api/runs/{id}`（含判定等级、核对项与后置动作结果）；`GET /api/runs/{id}/events?before_seq=`；SSE 同步尾部 |
| 叫停 | `POST /api/runs/{id}/stop`，body `{requestId}` |
| 配对 | `GET /api/health`；`POST /api/pair` |
| 设备 | `GET /api/devices`；`DELETE /api/devices/{id}` |
| 证据 | `GET /api/runs/{id}/evidence/{name}` |

认证：`Authorization: Bearer <token>`；SSE 用 OkHttp 请求头带令牌，不放 URL。

## 状态覆盖

每个页面覆盖：加载中、空、错误、离线、重连中。

- 离线与重连中：只读最近快照；叫停、冲突处理、设置保存禁用，并显示原因。
- 错误：人话 + 下一步动作；不显示堆栈与原始协议错误。
- 空：未配对引导配对；无运行显示待命与下次触发；无历史显示说明。

## M0 验收

在目标 Android 真机上：

1. 扫码配对 30 秒内完成；错误码/过期码有明确提示。
2. 总览首屏 1 秒内可交互（有缓存时）；SSE 事件 1 秒内反映。
3. 断网 30 秒后恢复，状态与电脑端一致，不重复、不丢步骤。
4. 叫停有二次确认；确认后 10 秒内收尾，界面以 `run.finished` 为准。
5. 三屏可往返；背景 30fps 稳定，详情页无明显掉帧。
6. 离线打开不崩溃，只显示缓存与「连不上电脑」。

## M0 不做

- 编排、脚本任务、前置操作、后置动作的完整编辑器；判定等级与后置动作在 M0 只读展示。
- 多主机切换界面。
- 离线写操作与本地排队重放。
- 文件编辑、Git/SSH、终端、语音、多人协作。
- FCM 推送与应用内更新（先手动装 APK）。

## 实现前确认

以下不阻塞设计，进入实现时再定：

- minSdk 26 还是 28；以目标机型和前台服务类型为准。
- 玻璃库用 backdrop 1.0.6 还是 Haze 2.x；先按 backdrop 对齐 dsh-mobile。
- 扫码用 ML Kit bundled 还是 ZXing；按 APK 体积与设备 Google 服务情况选。
- 通知用 ntfy 还是先只做本地通知；按是否要锁屏提醒选。
