# ADR 0001 · 分层与目录结构

- 状态：已采纳
- 日期：2026-10-18
- 修订：2026-10-20 手机端由 PWA 改为 Android 安装包；技术栈见 [ADR 0002](0002-手机端采用Android原生客户端.md)，对比见 [research/04](../research/04-安卓入口与技术栈对比.md)

## 背景

项目要托管无人值守的自动化脚本，提供电脑端与手机端界面，并允许远程查看和修改。既有做法的执行、判定、配置、界面在同一个 Python 包内，界面与主流程同进程；改一处容易牵连全局，界面卡顿会拖住自动运行。

## 决策

1. **核心进程与界面进程分离。** 核心进程 `backstop` 常驻，负责调度、执行、判定、兜底与存储，不创建任何窗口；界面是独立客户端，经本机 HTTP API 与核心通信。
2. **控制通道唯一。** 查看与修改都走 HTTP API；界面不直接读运行时文件、不直接操作模拟器。
3. **同一套 API，两种客户端。** 电脑端用 WebView2 窗口加托盘；手机端用 Android 安装包（APK），经 HTTP API 与 SSE 与核心通信。两端不共享页面代码。
4. **前后端同仓分目录。** 后端 `src/backstop/`，电脑端前端 `web/`，Android 客户端 `android/`；`web/dist/` 由核心进程托管。
5. **运行时数据与代码分离。** `data/` 存数据库、截图、日志，不进入版本库。

## 目录

```text
lap-backstop/
├─ README.md
├─ AGENTS.md
├─ TASKS.md
├─ pyproject.toml
├─ docs/
│  └─ adr/
├─ src/backstop/
│  ├─ __main__.py        入口：serve / run / doctor
│  ├─ core/              调度、运行器、步骤引擎、判定、兜底
│  ├─ adapters/          脚本适配器，arknights 为第一个
│  ├─ ai/                AI 服务
│  ├─ web/               FastAPI 应用、SSE、静态资源
│  ├─ storage/           SQLite、证据文件
│  └─ config/            默认配置与加载
├─ web/                  电脑端前端源码（React + Vite）
├─ android/              Android 客户端（APK）
├─ assets/               识别模板、图标
├─ scripts/              检查器与运维脚本
├─ tests/
└─ data/                 运行时生成，不入库
```

## 后果

- 界面崩溃不影响执行；核心不可达时界面显示离线，恢复后自动重连。
- 电脑端与 Android 客户端共用一套 API，接口契约只有一份；界面各自实现，各自适配交互。
- 需要长期维护 API 契约与前端构建链。

## 替代方案

- 单进程内嵌桌面界面：实现快，界面与执行互相拖累，不采纳。
- 每个脚本独立服务：隔离强，部署与权限复杂，不采纳。
