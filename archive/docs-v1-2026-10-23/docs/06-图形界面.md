# 06 · 图形界面

[返回总览](00-总览与索引.md)

## 原则

- 核心无界面；界面是客户端。
- 一套 API，两种客户端：电脑端 WebView2 窗口加托盘；手机端 Android 安装包。
- 两端只经 HTTP API 与 SSE 读取与修改，能力完全对等；界面代码各自实现。

## 电脑端

- 形态：托盘常驻，可打开窗口。
- 使用节奏：每天打游戏前打开看一眼，第一屏是今天的状态与待处理事项，设置入口放在顺手的位置。
- 启动：随用户登录启动；核心未运行时先启动核心。
- 托盘菜单：打开窗口、打开小窗、停止运行、当天跳过。
- 运行小窗：运行开始后在桌面右下角出现，显示当前步骤、已用时间与停止按钮；关闭小窗收进托盘，运行继续。
- 停止运行：停下本次运行，关闭 MAA、游戏与模拟器，并退出程序；下一次由计划任务拉起。
- 关闭主窗口：设置项，可选「收进托盘」或「直接关闭窗口」。
- 技术：pywebview（WebView2）加 pystray。

## 手机端

- 形态：Android 安装包（APK），直连电脑端核心；不依赖浏览器。
- 技术：Kotlin + Jetpack Compose 单模块；HTTP API + SSE。
- 用途：看状态、改编排、改脚本任务、处理冲突、叫停、看历史。
- 安装：签名 APK 由 GitHub Releases 发布；覆盖安装保留本地配置与配对状态。
- 更新：App 内检查版本，下载后校验 SHA-256 再交给系统安装；签名密钥固定并离线备份。
- 离线：显示「连不上电脑」，只读最近一次快照，不缓存敏感数据，不做离线写操作。
- 交互与动效参考：[research/02](research/02-手机端界面与动效.md)、[research/04](research/04-安卓入口与技术栈对比.md)。

## 页面

| 页面 | 内容 |
|---|---|
| 总览 | 今天的状态、待处理事项（冲突/失败/判不出）、当前运行与叫停、快捷动作 |
| 编排 | 时间点与时间段、脚本顺序、前置操作与后置动作挂载、判定等级、开跑前检查更新、启用开关、当天跳过 |
| 脚本任务 | 任务流程列表；进入流程编辑步骤顺序与参数 |
| 前置操作与后置动作 | 前置操作的准备段与收尾段；后置动作的步骤、参数、启停；方舟的后置动作含结束画面核对 |
| 冲突 | 差异项、程序值与脚本值、处理选择、默认策略设置 |
| 历史 | 运行列表、结论、证据、回放 |
| 助手 | 自然语言改任务，草稿与差异确认 |
| 设置 | 参数、判定默认等级、通知、AI 开关与预算、开机自启、计划任务、配对、导出备份 |

## 冲突页

每条冲突显示：

- 差异项：键、程序里的值、脚本里的值、最后修改时间。
- 四个选择：以程序为准、以脚本为准、逐项选择、暂不处理。
- 底部显示默认策略与修改入口。

缺少操作时的表现：

- 开跑前仍有未处理冲突，按默认策略自动解决，并在冲突页留下记录。
- 默认策略默认「以脚本为主」；可改为「以程序为主」。
- 脚本的完成后动作是程序接管字段：出现退出游戏或退出模拟器时标为接管项，按程序值重写并记冲突。

## 编排页

- 每个脚本一行：脚本名、前置操作、后置动作、判定等级、启用开关、顺序调整。
- 判定等级三选一：脚本口径、画面口径、双证据；默认值来自设置页。
- 后置动作可进入步骤编辑：步骤顺序、参数、启用开关；当前内置方舟任务核对。
- 时间用点选，支持多个时间点与时间段。
- 补跑窗口、跳过当天在同一页设置。

## 脚本任务页

- 左侧是任务流程列表，可增、删、复制、调整启用状态。
- 右侧是选中流程的步骤列表：顺序调整、参数编辑、启用开关。
- 改动保存后显示差异，确认后写入程序侧；脚本侧在开跑前对账时同步。

## 修改生效

- 保存即写入程序侧，并提示「下一次运行生效」。
- 判定等级与后置动作在运行开始时冻结；运行中的修改不打断当前运行。
- 正在运行的任务保持开始时的配置，不被打断。
- 下一次触发时读取新配置；冲突处理也在开跑前完成后再生效。
- 运行中的任务如需立即停下，用右下角小窗的停止按钮。

## 启动与计划任务

- 开机自启：开关；开启时登录自动启动程序，并注册登录触发的计划任务。
- 触发时间：在编排页修改，保存时同步更新兜底计划任务。
- 计划任务状态：显示是否已注册、上次运行结果；提供一键重新注册。
- 待命时只收修改、不干活，手机随时能连。

## 实时

- SSE 推送运行、步骤、后置动作、证据、判定、冲突与告警。
- 断线自动重连，重连后拉取一次全量状态。
- 快照、事件序号与断线重建的参考：[research/03](research/03-事件与同步.md)。
- 截图按需加载；列表用缩略图。

## 认证

- 首次启动生成一次性配对码，显示在电脑端窗口。
- 手机 App 扫码配对，换取长期设备令牌；令牌存 Android Keystore。
- 令牌只放在请求头；电脑端可查看设备列表并撤销。

## 响应式

- 手机竖屏优先：一屏看到「现在在做什么 / 今天成没成 / 叫停」。
- 电脑端两栏：左侧导航，右侧内容。
- 深色模式跟随系统。

## 状态设计

每个页面都覆盖四种状态：加载中、空、错误、离线。错误显示人话与下一步动作，不显示堆栈。

## 通知

- 每次运行结束立即发送，不设静音时段。
- 内容：结论、判定等级与核对结果、关键数据、失败时附截图入口。
- 手机 App 在前台时用 SSE 实时提示；后台用前台服务或 ntfy 推送。
- 运行结论经钉钉机器人或 Server酱³ 发送，通道可选，与 App 是否在线解耦。
- 更新失败与兜底停手单独发一条。
- 界面内告警作为补充。

## 可访问性

- 字号可调。
- 颜色对比度满足移动端阅读。
- 按钮最小点击区域 44 像素。
