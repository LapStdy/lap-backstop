# 11 · 代码规约

[返回总览](00-总览与索引.md)

本文只管代码怎么写。需求见 [01](01-需求与边界.md)，分层见 [02](02-架构.md)。

## 工具链

| 用途 | 工具 | 要求 |
|---|---|---|
| 格式化与静态检查 | ruff | 无错误，提交前自动格式化 |
| 类型检查 | mypy | 公开函数全部标注，不允许 `Any` 逃逸 |
| 依赖方向 | import-linter | 契约写在 `pyproject.toml` |
| 测试 | pytest | 见 [12](12-测试与质量门禁.md) |
| 交付物文字 | `scripts/check_artifacts.py` | 无高风险命中 |

## 目录与依赖方向

```text
web  →  core  →  adapters
        ↓  ↘
     storage  config
```

| 模块 | 允许依赖 | 禁止依赖 |
|---|---|---|
| `web` | `core` 的只读视图、`config` | `storage` 直连、`adapters` |
| `core` | `adapters`、`storage`、`config`、`ai` | `web` |
| `adapters` | `config`、标准库、第三方 | `web`、`core`（上下文由参数传入） |
| `ai` | `config`、标准库、第三方 | `web`、`storage` |
| `storage` | 标准库、第三方 | 其余全部 |
| `config` | 标准库、第三方 | 其余全部 |

禁止循环依赖。新增跨层调用先写 ADR。

## 命名

| 对象 | 规则 | 示例 |
|---|---|---|
| 模块与包 | 小写蛇形 | `run_engine.py` |
| 类 | 大驼峰 | `StepRunner` |
| 函数与变量 | 小写蛇形，动宾短语 | `load_schedule()` |
| 常量 | 大写蛇形 | `MAX_RETRY` |
| 私有成员 | 下划线前缀 | `_parse_time()` |
| 事件 | `域.动作` | `run.started` |
| 错误码 | `E_` 前缀，大写下划线 | `E_BACKSTOP_EXHAUSTED` |
| 配置键 | `段.键` | `arknights.sanity_stop_below` |

中文只出现在用户可见文案、日志消息与文档里；标识符一律英文。

## 函数

- 单一职责：一个函数只做一件事，名字能说清它做什么。
- 长度不超过 50 行；参数不超过 4 个，更多时用 dataclass。
- 不修改入参；纯函数优先。
- 可预期的失败用返回值表达（`Result` 或枚举）；程序错误用异常。
- 禁止裸 `except`，禁止吞异常。

```python
# 不好：一个函数干三件事，失败靠返回 None 表达
def do_everything(cfg):
    ...

# 好：职责清晰，失败有明确类型
@dataclass(frozen=True)
class LoginResult:
    ok: bool
    reason: str

def check_login_screen(frame: Frame) -> LoginResult:
    ...
```

## 类型

- 所有公开函数与方法的参数、返回值必须标注。
- 不允许用 `Any` 绕过；确实无法表达时用 `object` 并在调用处收窄。
- 数据结构用 dataclass 或 TypedDict，不用裸 dict 在模块间传。

## 错误处理

| 类型 | 例子 | 处理 |
|---|---|---|
| 用户错误 | 配置写错、任务不存在 | 返回明确提示，不抛栈 |
| 环境错误 | 模拟器起不来、网络超时 | 兜底策略处理，计入预算 |
| 程序错误 | 断言失败、类型不符 | 抛异常，记录现场，运行失败 |

- 异常必须携带上下文（任务、步骤、运行 id）。
- 面板与通知只显示人话，堆栈进日志。
- 每条错误码在 [03](03-数据模型与接口.md) 有定义。

## 日志

- 结构化输出，每行带 `run_id`、`task`、`step`、`level`、`event`。
- 级别：`DEBUG` 仅本地排查开启；`INFO` 关键节点；`WARN` 可自愈的异常；`ERROR` 需要人看的问题。
- 不打印密钥、令牌、手机号、截图内容。
- 日志写文件，按天或按运行切分。

## 配置

- 默认值集中在 `config/defaults.yaml`，启动时与用户配置合并。
- 每个配置项有：类型、默认值、取值范围、一句话说明。
- 启动时校验，不合法直接拒绝启动并指出哪一项。
- 禁止魔法数字；时间、次数、阈值都是配置项。

## 并发与超时

- 同一时刻只执行一个运行；其余排队。
- 运行在独立线程，共享状态加锁。
- 所有外部调用必须设超时；禁止无限等待。
- 长任务拆分步骤，每步都有超时。

## 外部调用

- HTTP：设置超时、重试上限与退避；不走系统代理（显式关闭）。
- 进程：启动后记录 pid 与启动时间，防止误杀同名进程。
- 文件：只用 `pathlib.Path`；编码统一 UTF-8。

## 注释与文档字符串

- 注释只写「为什么」，不写「改了什么」。
- 公开函数写 docstring：做什么、参数、返回、抛什么异常。
- 复杂判定写清依据来源（哪张图、哪行日志、哪条规则）。

## 代码规模上限

| 项 | 上限 |
|---|---|
| 函数行数 | 50 |
| 参数个数 | 4 |
| 圈复杂度 | 10 |
| 类行数 | 300 |
| 模块行数 | 500 |

超限不是硬性失败，但需要在评审里说明理由；同一个文件连续两次超限视为该重构。

## 测试代码

- 命名 `test_<行为>_<条件>_<期望>`。
- 不用 `sleep` 等时间；用可注入的时钟。
- 不连真实网络、不启真实模拟器；用录制数据与假实现。
- 每个测试独立，不依赖执行顺序。
