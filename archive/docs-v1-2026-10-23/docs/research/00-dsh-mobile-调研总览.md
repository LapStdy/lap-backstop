## 调研对象

| 部分 | 形态 | 版本与许可 | 作用 |
|---|---|---|---|
| dsh-mobile（Whaleness） | Kotlin Multiplatform 手机端，Android 用 Jetpack Compose，iOS 用 SwiftUI | 仓库提交 `a224348`（2026-10-19），MIT | 手机上的工作区、会话、实时回复、Agent 轨迹、审批、文件、插件与定时任务 |
| dsh-plugin-mobile-gateway | DSH 宿主侧 Cordis 插件 | 已安装 v0.10.3，MIT | 设备鉴权、WebSocket 网关、配对与可信设备、局域网与 Tunnel 入口 |
| dsh-pocket | DSH 宿主侧 Cordis 插件，另一作者 | 已安装 v2.12.0，GPL-2.0 | 把 DSH WebUI 整站反向代理到手机浏览器，注入移动端适配 |

「两个插件和一个手机端」在本机安装环境里对应上表三行。三者不是同一仓库的一套东西：dsh-mobile 是手机端仓库；网关在兄弟仓库 `Clarklevis1995/dsh-plugin-mobile-gateway`；口袋是 `shaobeichen/dsh-pocket`。网关的手机端就是 dsh-mobile 原生 App，口袋的手机端是浏览器页面。

## 它解决什么问题

电脑上的 DSH 长时间跑 Agent，人离开电脑后仍要看到进度、发消息、处理审批。dsh-mobile 的做法是：

```text
手机 App / 手机浏览器
        │  WebSocket（网关）或 HTTP 反向代理（口袋）
        ▼
宿主插件（网关 / 口袋）
        │  DSH Remote Gateway、会话事件、WebUI
        ▼
电脑上的 DSH 进程
```

网关自定义 `dsh-mobile-v1` 协议，把 DSH 的会话、实时流、审批、文件等投影成稳定帧；口袋不做协议，直接透传 WebUI。两者默认都监听 3081，同一台机器同时启用会争端口：口袋自动顺延到 3090，网关的局域网监听失败只记日志（源码推断，未实测同开表现）。

## 与 lap-backstop 的关系

两者问题形状相同：一台常开的 Windows 电脑跑无人值守任务，手机在别处看状态、改配置、处理需要人决定的请求。对象模型不同：dsh-mobile 是「会话 / 回合 / 消息 / 审批」，lap-backstop 是「编排 / 运行 / 步骤 / 判定 / 冲突」。

可直接借的是机制，不是代码：

| 主题 | 对 lap-backstop 的价值 | 详见 |
|---|---|---|
| 配对与设备台账 | 一次性配对码换长期令牌、令牌只存摘要、设备可撤销、重配对复用设备行 | [01](01-远程访问与配对.md) |
| 入口分层 | 管理面仅 loopback；局域网独立监听；公网只开一条精确路径 | [01](01-远程访问与配对.md) |
| 错误语义 | 401 / 503 / 4003 / 4004 区分「凭证失效」「服务未开」「被吊销」「被关闭」 | [01](01-远程访问与配对.md) |
| 快照加增量 | 先原子快照，再按单调序号推增量；断档即重建基线 | [03](03-事件与同步.md) |
| 分页与实时合并 | 历史按游标分页，实时尾部按序号去重，实时覆盖同序号 | [03](03-事件与同步.md) |
| 交互单胜方 | 审批与提问多端只生效一次，迟到响应返回 not-pending；写操作带 revision 做 CAS | [01](01-远程访问与配对.md)、[03](03-事件与同步.md) |
| 界面与动效 | 深海背景、液态玻璃、卡片入场、语音粒子遮罩、大屏适配 | [02](02-手机端界面与动效.md) |

## 不照搬的部分

| 部分 | 原因 |
|---|---|
| KMP / MVI 强类型桥 | 为 Kotlin 与 Swift 跨语言一致性设计；lap-backstop 是 Python + React 单进程，引入后成本大于收益 |
| 自定义 WebSocket 业务协议 | lap-backstop 已定 HTTP + SSE；再加一套帧协议会让接口与状态源分叉 |
| 双物理连接 split-channels | 为上游流与文件传输抢队列设计；SSE 单向流没有对应问题 |
| 附件 base64 内联 | 证据与文件走下载接口，SSE 只发引用与摘要 |
| 整站反向代理 + 页面注入 | lap-backstop 手机端是专门 Android 客户端，不把桌面布局搬进手机 |
| 默认开放公网 | 与 lap-backstop 安全边界 S-104「控制面只在局域网可达」冲突；公网接入需要单独决策并改边界 |
| 口袋的 GPL-2.0 代码 | 不能直接移植；网关 MIT 代码可借鉴，需保留版权声明 |
