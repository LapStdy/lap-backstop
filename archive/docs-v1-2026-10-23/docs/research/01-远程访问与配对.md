# 01 · 远程访问与配对

[返回调研总览](00-dsh-mobile-调研总览.md)

## 结论

dsh-mobile 的远程访问由三层组成：本机管理面只走 loopback；局域网开一个只接受鉴权连接的独立入口；公网通过 Tunnel 只暴露一条精确路径。手机第一次用一次性配对码换长期令牌，之后每次连接只带令牌；服务端只保存令牌的 SHA-256 摘要，设备可单独撤销。

这套模型可以直接映射到 lap-backstop 的「电脑端管理 + Android 客户端」：配对、设备台账、令牌摘要、撤销、错误语义都能沿用；传输从 WebSocket 改成 HTTP + SSE，公网入口暂不启用。

## 入口分层

| 入口 | dsh-mobile 的做法 | 规则 | lap-backstop 的对应 |
|---|---|---|---|
| 本机管理 | DSH WebUI 与 `/mgw/*` 管理接口 | 仅 127.0.0.1；写操作另校验同源 | 电脑端窗口与 `/api/admin/*` 只监听 127.0.0.1 |
| 局域网 | 独立监听 `0.0.0.0:3081/ws/mobile` | 只接受该路径与私网源地址；非私网 403，其他路径 404；始终强制鉴权 | FastAPI 监听 `0.0.0.0:<port>`，手机入口与电脑管理面分端口 |
| 公网 Tunnel | `127.0.0.1:3082`，由 cloudflared 回连 | 只接受 `/ws/mobile`；其他路径 404；仍需设备令牌 | 暂不启用；将来用 Tailscale 或 WSS 反向代理时保持同样边界 |

关键点不是端口号，而是「管理面与手机面分开」：管理接口永远不跟着局域网监听一起暴露；公网入口只放行一条业务路径，不把整个 WebUI 或 API 树暴露出去。

## 配对流程

### 载荷

二维码与手动复制内容是同一个无 padding 的 Base64URL 字符串，解码后是 JSON：

```json
{
  "version": 2,
  "publicUrl": "ws://192.168.1.10:3081/ws/mobile",
  "pairingCode": "<一次性 256 位随机码>",
  "expiresAt": 1787112000000,
  "gatewayId": "<持久 UUID v4>",
  "gatewayName": "家里电脑",
  "endpoints": ["ws://192.168.1.10:3081/ws/mobile"]
}
```

- 载荷只做编码，不做加密；保密性来自短有效期与一次性。
- 配对码 32 字节随机数，只存在内存，Map 键是它的 SHA-256 摘要；默认 5 分钟过期，进程重启即失效。
- 二维码里不放长期令牌；长期令牌只在配对成功后的 `paired` 帧里下发一次。

### 首次连接

1. 电脑端生成配对码与二维码，显示在「移动设备」或「手机访问」页面。
2. 手机扫码，严格按 Base64URL 解码，检查 `version`、`expiresAt` 与地址格式。
3. 手机带稳定安装级设备 ID 发起连接，用配对码完成鉴权；缺少设备 ID 会被拒绝，避免每次重连新建设备行。
4. 服务端回 `paired`（长期令牌 + 设备信息），再回 `hello`（协议版本、能力列表、鉴权状态）。
5. 手机把令牌写入平台安全存储；之后的连接只带令牌，不再带配对码。
6. 重配对时，设备 ID 命中未撤销设备就复用原设备行并轮换令牌，不产生重复设备。

### 令牌与设备台账

| 项 | 规则 |
|---|---|
| 令牌 | 32 字节随机数；客户端保存明文，服务端只存 SHA-256 摘要 |
| 比较 | 定长十六进制 + `timingSafeEqual`，避免时序侧信道 |
| 设备行 | `id`、`name`、`clientDeviceId`、`tokenHash`、`createdAt`、`lastSeenAt`、`revokedAt` |
| 同名设备 | 显示时自动加编号后缀，避免两台「iPhone」分不清 |
| 撤销 | 真删设备行、清在线计数，并让该设备的在线连接收到关闭码 |
| 落盘 | 同目录临时文件 + 原子改名，权限 0600；损坏时报错，不静默生成新身份 |

### 错误与关闭语义

| 状态 | 含义 | 手机端动作 |
|---|---|---|
| HTTP 503 | 移动网关未开启 | 停止高频重连，等用户在电脑端开启后重试 |
| HTTP 401 | 无凭证、令牌失效、配对码过期或重复使用 | 删除旧令牌，进入重新配对 |
| HTTP 400 | 配对请求缺设备 ID | 升级客户端 |
| close 4003 | 重新开启鉴权，或该设备被吊销 | 用令牌重连或重新配对 |
| close 4004 | 移动网关被关闭 | 停止自动重连 |

这套语义把「服务没开」「凭证坏了」「被管理员踢了」「被关闭了」分开，手机端不会把所有失败都当成网络问题反复重试。

### 重连节奏

- 失败后指数退避：2 秒、4 秒、8 秒……封顶 30 秒，最多 6 次。
- 配置多个候选地址时轮换尝试。
- 回到前台先探测，短超时无响应再快速重连。
- 手动配对失败不自动重试，避免一次性码被反复使用。

## 多主机与候选地址

- 网关身份是持久 UUID v4；展示名可改，不能当身份或鉴权依据。
- 候选地址规范化去重，最多 16 项，每项最多 2048 字符；公网地址必须是 `wss`，拒绝通配地址、凭证、query 与 fragment。
- 每个网关的令牌独立签发、独立撤销；App 以连接上下文路由请求。
- 切换主机是重建连接与状态，不是在同一连接上切命名空间。

lap-backstop 的多机是长期方向。单机阶段只需要在设备表与配置里预留「电脑标识 + 候选地址」，不做切换界面。

## 对 lap-backstop 的接口形状

以下形状与现有 `docs/03` 的 `/api/pair` 和 `X-Backstop-Token` 兼容，只补设备维度与错误语义。

| 方法 | 路径 | 说明 |
|---|---|---|
| POST | `/api/pair` | 入参 `{code, device_name, client_device_id}`；返回 `{token, device}` 并设置会话 Cookie |
| GET | `/api/devices` | 设备列表：名称、创建时间、最后在线、在线连接数 |
| DELETE | `/api/devices/{id}` | 撤销设备；在线连接立即失效 |
| GET | `/api/health` | 返回 `{version, capabilities, server_time}`，供手机按能力开关入口 |
| GET | `/api/status` | 全量快照；SSE 断线重连后先取它 |
| GET | `/api/events` | SSE；带 `Last-Event-ID` 或 `since_seq` |

设备表建议字段：`id`、`name`、`client_device_id`、`token_hash`、`created_at`、`last_seen_at`、`revoked_at`。只存摘要，不存明文令牌。

### 客户端令牌存放

Android 客户端：令牌用 Android Keystore 的 AES-GCM 加密后保存；请求头带 `Authorization: Bearer`；SSE 用 OkHttp 请求头带令牌，不放 URL。

如果保留 PWA（只作对照）：

| 方案 | 优点 | 风险 |
|---|---|---|
| localStorage / IndexedDB 存 Bearer 令牌 | 实现简单，API 统一 | XSS 可读；PWA 没有 Keychain/Keystore |
| 配对后设 HttpOnly + SameSite=Strict 会话 Cookie | 脚本读不到；SSE 可直接用 | 需要 CSRF 防护；多主机要按域隔离 |
| `fetch` 流式读取 SSE + Authorization 头 | 不用 Cookie，SSE 仍可带凭证 | 不能用原生 `EventSource`，要自己解析事件流 |

Android 端不引入 Cookie 会话；Cookie 方案只作为浏览器/桌面端的对照。

### 公网边界

lap-backstop 现行安全边界 S-104 是「控制面只在局域网可达，不直接暴露公网」，R-1102 是「不依赖公网，局域网或组网工具访问」。dsh-mobile 的 Cloudflare Quick Tunnel 虽然不开放路由器入站端口，但仍把控制面暴露到公网 URL，和 S-104 冲突。

可采用的程度：

- 局域网直连：直接可用。
- Tailscale / 组网工具：仍在一个私有网络内，最接近 R-1102，可作为出门访问的首选。
- Cloudflare Quick Tunnel / 公网 WSS：需要单独决策，先改 S-104 并写 ADR；同时必须强制 WSS、设备令牌、登录限速与路径白名单。

## 安全清单

- 管理接口只监听 loopback，写操作校验同源。
- 局域网入口始终要求设备令牌，Debug 开关不能把它变成匿名控制面。
- 长期令牌只存摘要；配对码一次性、内存态、短 TTL。
- 令牌不放 URL query，避免被代理日志、浏览器历史记录。
- 公网只放行一条业务路径，其他路径 404；公网必须 TLS。
- 设备可撤销；撤销即断开在线连接。
- 登录失败限速：按 IP 与全局双阈值，避免暴力破解与分布式扫描。
- 失败关闭：服务未开返回 503，鉴权失败返回 401，不降级为匿名连接。
