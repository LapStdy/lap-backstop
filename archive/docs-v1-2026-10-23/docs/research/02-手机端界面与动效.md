# 02 · 手机端界面与动效

[返回调研总览](00-dsh-mobile-调研总览.md)

> 手机端形态是 Android 安装包；本文的 PWA 复刻章节只作为降级与对照，原生实现优先。Android 技术栈对比见 [04](04-安卓入口与技术栈对比.md)。

## 结论

dsh-mobile 的视觉骨架是「深海渐变 + 点阵鲸鱼 + 液态玻璃」，动效风格是「短、快、少弹」：页面转场 260ms，弹层 160–220ms，抽屉与滑动删除用刚度 450 的无回弹弹簧，列表本身不做逐条进场。

对 lap-backstop 的 Android 客户端，值得复刻的是三层：深海背景给「常驻任务」以稳定氛围；玻璃卡与状态点给「现在在做什么 / 今天成没成」以清晰层级；42–52dp 的圆形主操作与停止方块给「一键叫停」以明确手感。AGSL 折射、585 粒子全量动画、真实背景采样不适合在 Web 上硬搬，按性能取舍。

### 字体

- 系统默认字体；ID、耗时、代码用等宽字体；数字统一表格数字（`tnum`）。
- 首页标题 32sp Bold；二级页标题 22sp Bold；卡片/面板标题 18sp；顶栏与设置行 17sp；正文 16sp；辅助 13–14sp；状态与 ID 12sp。
- 字号可调 0.8–1.5 倍，13 档（每 5% 一档），默认 1.0；跟随系统时忽略应用倍率。

### 液态玻璃

| 风格 | 模糊 | 折射高度 | 折射强度 | 表面白 | 描边白 | 阴影 | 用途 |
|---|---|---|---|---|---|---|---|
| CONTROL | 4dp | 11dp | 18dp | 0.050 | 0.25 | 15dp | 52dp 圆按钮 |
| CARD | 5dp | 14dp | 23dp | 0.005 | 0.20 | 20dp | 工作区卡 |
| ACTION | 5dp | 16dp | 26dp | 0.012 | 0.26 | 22dp | 主操作按钮 |
| FIELD | 5dp | 10dp | 16dp | 0.060 | 0.10 | 14dp | 搜索框 |
| SUBTLE | 4dp | 8dp | 13dp | 0.040 | 0.10 | 12dp | 空态卡 |

- 效果链：提亮 → 亮度 1.005、对比 1.03、饱和 0.72 → 曝光 +0.015 → 模糊 → 折射（景深 + 色散）。
- 高光 0.90dp 宽、0.75dp 模糊；外阴影黑 9%；内阴影 4dp、透明度为描边的 22%。
- API 31 以下降级为「白 5% 填充 + 0.8dp 白描边」；弹层毛玻璃 `blur 24dp`，浅色 tint `#E8EDF5` 68%、深色 `#22252C` 76%。
- 页面玻璃只采样背景层，弹层采样整页，避免递归重影。

## 三个招牌动效

### 深海动态背景

- 组成：流体场 + 技术网格 + 鲸鱼粒子 + 底部渐隐。
- 帧率：30fps 固定节流（帧闸 33.33ms），时间按 4096 秒取模；手势或列表滚动时冻结在当前帧，恢复后接着播放。
- 流体场：API 33+ 用 AGSL，颜色深黑 `#000204`、深蓝 `#1A3870`、海蓝 `#204A7E`、雾蓝 `#538DC9`、暖光 `#EED8AA`；时间缩放 0.075；旧系统降级为径向渐变 `#234B79 → #101F3B → #010510` + 12 层低透明描边光弧。
- 技术网格：间距 42dp（大屏 42–64dp），线宽 0.55dp、白色 4.3%；每 `(row×11 + column×7) % 13 == 0` 画 2.2dp 亮点，白色 8.5%。
- 鲸鱼粒子：72×72 采样（大屏 100×100），从鲸鱼 SVG 栅格化取内部点；漂移 ±4dp、尾波 10dp、相位 0.42/0.50 rad/s、闪烁 1.5 rad/s、透明度上限 0.42。
- 暂停：系统动画时长比例为 0 时鲸鱼静止；页面不可见时停止帧循环。

### 液态玻璃

- 玻璃由「背景采样 + 模糊 + 折射 + 高光 + 内外阴影 + 白色渐变表面」组成。
- 关键参数见上表；主按钮额外叠 6% Navy 内着色。
- 弹层用独立窗口采样整页，页面内玻璃只采样背景层；跨窗口时按屏幕坐标平移对齐。
- Web 端用 `backdrop-filter: blur(5px) saturate(.72) brightness(1.005) contrast(1.03)` + 白色 inset 高光 + 外阴影近似；不支持时退回「白 6% + 0.8px 白描边」。

### 按住说话粒子遮罩

- 触发：语音模式按住「按住说话」；80ms 内抬手视为点击，不录音。
- 高度：窗口高 40%，贴底，覆盖导航栏；进场 160ms 淡入 + 18dp 上滑，退场 280ms 淡出。
- 粒子：45 柱 × 13 = 585；20 秒线性无限循环；自由漂移 ±14dp/±12dp；收束动画 160ms（波形态）/320ms（自由态）。
- 几何：柱距 ≤6.4dp；柱高 `5 + level×56×(0.35+0.65×sin 包络)` dp；中心线在 68% 高度。
- 配色：浅色 `#73A9E7 / #AFD7FA / #173C65`；深色 `#203B5C / #39658F / #E3F0FF`；取消态粉红 `#F0ACBA / #FFD6DA / #642434`。
- lap-backstop 可以不照搬语音，但可把这套「粒子收束成波形」用于「按住确认叫停」或「长按覆盖配置」的反馈。

## PWA/WebView 降级复刻建议（对照）

| 动效 | 复刻参数 | 实现建议 | 降级 |
|---|---|---|---|
| 深海渐变底 | 径向渐变 `#234B79 → #101F3B → #010510`，中心横向漂移 ±8%，7.5s 周期 | 2–3 层 `radial-gradient` + `translate3d` | 静态渐变图 |
| 流体背景 | 4 层 fbm、时间 ×0.075、30fps 上限 | WebGL fragment shader；不可见时停止渲染 | Canvas2D 0.5× 或纯 CSS 光弧 |
| 技术网格 | 42px 间距、白色 4.3%、0.55px | 单层 `repeating-linear-gradient` + 底部 `mask-image` 渐隐 | 关闭网格 |
| 鲸鱼粒子 | ±4px 漂移、10px 尾波、0.42–0.50Hz、1.5Hz 闪烁、透明 ≤0.42 | 预生成鲸鱼遮罩后采样；400–600 点 | 静态鲸鱼图 + 6s 呼吸 |
| 玻璃卡 | `backdrop-filter: blur(5px) saturate(.72)`；白面 0.5%–6%；0.8px 白描边；外阴影 9% | 半透明 + 两段 `linear-gradient` 高光 | 白 6% + 描边 |
| 玻璃弹层 | 进 220ms + spring（stiffness 400 / damping 35），`scale .16→1`；退 180ms | Framer Motion，`transform-origin` 设触发点 | 180ms 缓动 |
| 抽屉 | 跟手 `translateX`；spring(450, 42)；速度阈值 400px/s；主页面圆角 48px×进度 | Pointer Events + rAF 写 CSS 变量；Framer Motion `useMotionValue` | 点按开关 + 240ms |
| 按压 | Android Chrome `navigator.vibrate(8–10)`；同交互只触发一次 | 仅移动端 | `scale(.97)` 60ms |
| 语音/长按浮层 | 160ms 淡入 + 18px 上滑；280ms 淡出；45 柱 | Canvas2D 波形 + 少量粒子 | 只保留波形 |
| 页面转场 | 260ms 左/右滑 | `translateX(100%)` 推入；返回反向 | 120ms 淡入 |
| 大字号 | 0.8–1.5 倍；1.5 倍以上切单列 | `html { font-size: calc(16px * var(--scale)) }` | 三档 |

性能取舍：

- 不要在 WebView/PWA 同时跑流体 shader 与 585 粒子；首页只保留一种主背景。
- `backdrop-filter` 在低端 Android 与 iOS Safari 上合成差异大，卡片多时改用半透明纯色 + 描边。
- 所有动效尊重 `prefers-reduced-motion: reduce`；开启时关闭背景与粒子，保留 120ms 淡入。
- 运行中的页面不做无限循环动画，避免看板长时间亮屏耗电；只在「运行中」状态显示呼吸点或鲸尾。

## 三个核心信息的落位

| 信息 | 借用点 | 具体参数 |
|---|---|---|
| 现在在做什么 | 顶栏连接点 + 单行「运行中」+ 执行统计胶囊 | 7–8dp 发光点（Success，光晕 5dp/28%）；胶囊 13dp 圆角、12sp 等宽数字 |
| 今天成没成 | 分组卡 + 结论色点 + 三组指标 | 22dp 圆角卡、行高 ≥54dp；完成 Success、失败红、未开始 35% 白 |
| 一键叫停 | 42–52dp 圆形主操作，运行中切换为停止方块 | Ocean 圆、内含 14dp 白方块（3dp 圆角）、不可用 66% 透明；确认弹窗 28dp 圆角、按钮 48dp 高 |

一屏顺序建议：顶部连接与时间 → 当前任务卡 → 结论卡（今天/最近一次）→ 底部固定「叫停」与「打开电脑端」。用 CSS Grid 行高 `minmax(64px, auto)` 保证竖屏首屏能看到叫停按钮。
