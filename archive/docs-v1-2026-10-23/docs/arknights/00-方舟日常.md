# 方舟日常

本文件是方舟专属文档的总入口。当前项目唯一的托管对象是 MAA 与明日方舟；其他脚本在接入时另写各自文档。

## 一次日常的完整过程

```text
03:00 / 15:00 触发（时间可配）
  → 前置操作
      环境准备：系统音量、运行期防睡眠
      启动或复用 MuMu 模拟器
      拉起明日方舟
      等登录界面，识别到后按固定安全坐标点登录
      等到主界面（多套主题模板）
  → 配置对账：读 MAA 配置，比较差异，按默认策略处理
  → 写入 MAA 配置
  → 启动 MAA，按 MAA 的任务流程执行
  → 监控：MAA 日志为主，定时抽帧看画面
  → 后置动作：截图核对 MAA 任务是否完成，产出画面证据
  → 判定：按判定等级取 MAA 结果与画面证据 → 完成 / 未完成 / 判不出
  → 收尾：恢复音量、释放防睡眠
  → 通知
```

## 时间与参数

| 项 | 默认 | 说明 |
|---|---|---|
| 触发时间 | 03:00、15:00 | 可改、可加 |
| 补跑窗口 | 180 分钟 | 关机或睡眠错过后的补跑 |
| 启动模拟器超时 | 3 分钟 | |
| 等登录超时 | 15 分钟 | |
| 等主界面超时 | 5 分钟 | |
| 系统音量 | 10% | 运行前设置，结束后恢复 |
| 防止睡眠 | 开 | 运行期间阻止睡眠与熄屏 |
| 抽帧间隔 | 30 秒 | MAA 运行期间的画面抽查 |
| 判定等待 | 60 秒 | MAA 结束后静置再判定 |
| 判定等级 | 双证据 | 脚本口径 / 画面口径 / 双证据 |
| 后置动作 | 结束画面核对 | 截图核对 MAA 任务是否完成 |
| 分辨率 | 1280×720 | 模拟器与 MAA 保持一致 |

以上全部在界面可改，默认值由程序给出。

## 前置操作

准备段：

1. 环境准备：设置系统音量、开启防睡眠。
2. 清理残留（默认关闭）：结束残留的游戏与 MAA 进程，按白名单。
3. 启动或复用模拟器：已经运行就复用，否则启动并等待可用。
4. 拉起游戏：启动客户端。
5. 等登录：识别登录界面，点固定安全坐标的登录按钮。
6. 等主界面：识别到主界面（多套主题模板）即视为准备好。

收尾段：

7. 恢复系统音量、释放防睡眠。

失败处置：

- 模拟器起不来：重试一次，仍失败则停手通知。
- 登录界面等不到：重启游戏一次，仍失败则停手通知。
- 主界面等不到：重试点击登录两次，仍失败则停手通知。

## 后置动作

后置动作在 MAA 结束后、判定之前执行，不承担环境恢复。

当前核对内容：

| 检查项 | 判据 | 证据 |
|---|---|---|
| 主界面 | 任一主界面模板命中 | 截图、模板名、得分 |
| 异常画面 | 没有错误框、掉线、维护、更新或未知画面 | 截图、模板名、得分 |

- 判定等级为画面口径或双证据时，后置动作的画面证据参与结论；为脚本口径时证据只记录。
- 逐任务核对由额外步骤组成：理智、每日任务、基建、公招、信用等，每步使用独立画面探针与证据。
- 后置动作拿不到画面或识别失败时记证据缺失：画面口径与双证据记判不出，脚本口径只记录；不降级为完成。
- MAA 的完成后动作由程序接管：MAA 只退出自身，游戏与模拟器由收尾段关闭。

## 判定口径

判定等级是每个脚本运行的配置项：

| 等级 | 判据 | 另一来源的用途 |
|---|---|---|
| 脚本口径 | MAA 队列完成、无报错、退出状态 | 画面证据只记录 |
| 画面口径 | 后置动作的结束画面核对 | MAA 结束信号只用于触发核对 |
| 双证据 | MAA 结果与画面证据同时参与 | 两者都参与 |

三态结论：

| 结论 | 判据 |
|---|---|
| 完成 | 按等级选中的证据都指向完成 |
| 未完成 | MAA 报告失败或未完成，或画面明确停在错误或未完成状态 |
| 判不出 | 证据矛盾、证据缺失、截图不可读；双证据下 MAA 说完成但画面异常也记判不出 |

- 判定证据：MAA 日志尾部、后置动作截图与识别结果、MAA 退出状态。
- 不登录账号拉取官方数据。

## 识别模板

| 模板 | 用途 |
|---|---|
| 登录界面 | 判断可以点登录 |
| 登录按钮 | 固定安全坐标点击 |
| 主界面（多套主题） | 准备好与判定完成 |
| 游戏错误框 | 识别并关闭后重试 |
| 活动弹窗关闭按钮 | 挡路时关闭 |
| 掉线提示 | 后置动作识别异常画面 |
| 维护/更新中 | 后置动作识别等待状态 |

- 采集：在目标界面截图，主体尺寸 40 到 80 像素，采集后跑一次验收。
- 失效：游戏改版后模板失配，重新采集；连续失配时 AI 建议采集区域。
- 危险区域：左上角「清除缓存」按钮所在区域，任何配置都不能让点击落进去。

## 通知

- **每次运行结束立即发**，不限时段：完成、未完成、判不出都发。
- 内容：结论一句 + 判定等级与核对结果 + 关键数据（理智、日常完成项）+ 失败时附截图入口。
- 渠道：钉钉与 Server酱³，可单独开关。
- 更新失败、兜底停手单独发一条。

## 边界

- 不修改游戏客户端文件，不注入、不破解。
- 不修改 MAA 程序文件，只读写其配置与日志。
- 点击只用固定安全坐标，危险区域黑名单。
